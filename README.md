# AtmoSync: Micro-Climate Arbitrage Analytics

## About the Project

AtmoSync is a Data Analytics project that analyzes micro-climate and weather data to identify trends, patterns, and useful insights across different locations.

## Objectives

- Collect weather data
- Clean and validate the dataset
- Analyze weather conditions
- Compare different locations
- Create visualizations
- Develop an interactive dashboard
- Identify useful micro-climate insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- PostgreSQL
- SQL
- Power BI
- GitHub

## Dataset

The project uses weather-related data containing parameters such as:

- Date
- City
- Temperature
- Humidity
- Rainfall
- Wind Speed
- Pressure
